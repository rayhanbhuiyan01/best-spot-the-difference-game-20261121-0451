Lantern Garden — a complete, original spot-the-difference game that runs offline in a desktop browser from static files. Three hand-drawn canvas scenes (Garden Dawn, Riverside Picnic, Night Market), 7 hidden changes per scene, two pictures side by side with green circle markers on every difference found, a live "Found X / 7 · Y to go" counter, a countdown timer with time pressure, hints (H), score with time bonus, wrong-click penalty, synthesized sound effects (no audio files), and full keyboard + mouse play. No network requests, no libraries, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome and play. Or open `game/index.html` from any static server.
